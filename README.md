# 🍬 DulceStock

Sistema inteligente de ventas y abastecimiento para una dulcería familiar.

Incluye un punto de venta para registrar ventas e inventario, y un módulo de Machine Learning que estima la demanda de cada producto y recomienda cuánto pedir a cada proveedor.

## Tecnologías

- **Frontend:** React + TypeScript
- **Backend:** Python + FastAPI
- **Base de datos:** PostgreSQL + SQLAlchemy
- **Machine Learning:** Pandas, Scikit-learn
